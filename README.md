Entry for the [One-Line Office Jokes](https://make.fun/c/u-markk-st-one-line-office-jokes-a51f2bcc) competition on make.fun.

`main.py` writes one single-line joke about office life to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output`):

> I replied-all to ask everyone to stop replying-all, and now 47 people are agreeing with me in a thread called 'Please stop'.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
